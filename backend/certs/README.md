# 证书目录

此目录用于存放微信支付相关证书文件。

## 需要放置的文件

请将以下微信支付证书文件放置在此目录：

- `apiclient_cert.p12` - 商户证书（p12格式）
- `apiclient_cert.pem` - 商户证书（pem格式）
- `apiclient_key.pem` - 商户私钥（pem格式）

## 获取证书

这些证书可以从微信商户平台下载：
1. 登录微信商户平台 (https://pay.weixin.qq.com)
2. 进入「账户中心」->「API安全」
3. 下载商户证书

## 注意事项

- 证书文件包含敏感信息，**不要提交到代码仓库**
- 证书文件已在 `.gitignore` 中配置为忽略
- 请确保证书文件权限设置为仅所有者可读
