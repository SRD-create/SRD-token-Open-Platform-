# aitoken_platform_frontend_nexus

AI Token Platform Frontend Nexus - 前端应用

## Getting started

### Prerequisites
- Node.js 18+
- Yarn or npm

### Installation

1. Clone the repository:
```bash
git clone https://github.com/your-username/aitoken_platform_frontend_nexus.git
cd aitoken_platform_frontend_nexus
```

2. Install dependencies:
```bash
yarn install
```

3. Configure environment variables:
```bash
cp .env.example .env.development
```

Edit `.env.development` file with your configuration.

4. Run the application:
```bash
yarn dev
```

5. Build for production:
```bash
yarn build
```

## Features
- User authentication with WeChat
- API Key management
- Token package management
- Model marketplace
- Admin dashboard
- Multi-language support
